# A robot that follows the Simple conversation activity (shipped)

The Simple conversation status line shows three dots that gather into a shaded robot.
Thinking, Running commands, Reading, Writing, Editing, Searching, Browsing and Working
each have their own gesture. The eyes turn across the sphere, with small changes in
timing and tilt from one entrance to the next.

The status text updates with the tool activity. Each gesture is chosen at the start
of the transformation and finishes before the latest activity can pick another.
Reduced motion uses static dots. Approval cards and the end of a turn still take the
status line away.
