Why: the scheduled Windows run of 11-09 (run 152, main at 5f650bb) failed two tests and broke a count of 12 green nights toward the 14 of #232.

## Shipped
- `tests/web/test_workspace_files.py`: the tree wrote `app.py` with `write_text`, which on Windows writes CRLF, so the listed size was 10, not 9. It is written as bytes now. The listing code was right.

- `docs/plan.md`: the maintainer line records the night.
