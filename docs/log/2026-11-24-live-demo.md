# Promo page: the demo replays the real conversations in the app's own interface (shipped)

Why: the screenshot demo was true but static; the maintainer wanted the earlier interactive feel
with the real interface.

## Shipped
- `site/demo/` replays the ten real runs (five tasks, English and Chinese) from the Windows
  desktop app. Every piece on screen is what the real UI drew for that conversation:
  `tools/capture.cjs` gives a running `coscribe-web` the exported socket events in Playwright,
  posing as the desktop shell, and saves the window, the replies, each call's opened view, the
  notice and file card, the panel (slides fetched as SVG from the server, the Doc editor, the
  Browser panel asking for the site and in use) and the running composer. The page uses the
  app's built stylesheet and fonts, and names calls with the app's own `transcriptGrouping.ts`,
  bundled into `labels.js` (`tools/build.sh`). How to redo it: `site/demo/tools/README.md`.
- It plays like the app: the prompt typed on the start page, steps arriving with the running
  label, the turn timer counting through the run's real length in fast forward, the reply, the
  notice, then the made file opened. Steps and each step's view open on click, the notice and
  the file chip open the panel, thumbnails change the slide, the panel closes; the web task's
  sample CRM is live in the Browser panel and is set to the filter and page the run used.
- The homepage embeds it (`site/index.html`): the tabs pick the task, the bar under a tab fills as
  it plays, the tour moves on when a task ends, and it pauses off screen and with the play button.
  On a phone the window is drawn narrower and taller, with the panel over the chat. The old
  screenshots (`site/media/demo/`) are gone.
- Changed for presentation, each listed in `site/demo/tools/README.md`: two English replies that
  came back partly in Chinese and Spanish are in English; dollar amounts are escaped so they are
  not drawn as maths; tools the app shows by raw name are worded like its other calls.

## Not verified
