# Custom model entry, provider tests and additional API formats (shipped)

Users who know their model ID or deployment name can connect without model discovery.
A successful streaming reply and successful tool-result round trip report separate findings.

## Shipped

- The Providers settings page offers manual model entry and two on-demand model tests.
- Custom providers can use Responses or versioned Azure OpenAI with an API key. Legacy
  configurations use their existing resolution path. See decision 0061 for Azure.

## Not verified

- Live Azure and Responses vendor accounts. The integration tests exercise SDK requests and
  streamed responses for all three formats.
