# Workspace folder card and Plugins Add menu (shipped)

The workspace folder now uses the same row as the rest of its settings, and the
Plugins Add menu fits its actions on one line.

## Shipped

- Clicking anywhere in the Folder row or pressing Enter on it opens the folder picker.
- The Plugins Add menu grows to fit the upload label.
