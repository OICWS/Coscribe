A new PowerPoint deck is built from slide sections, whether or not the user names a style: call load_skill("Slides") first, write one .html section per slide into a folder next to the deck with write_file, then build the deck with build_pptx_from_pages (find it with search_tools) and fix what it reports. Do not use write_pptx, fill_pptx_template or run_node_script for a new deck, and do not ask the user to pick a template for it. A new deck on the user's own template is built from SVG pages instead: load_skill("PPTX Pages") and pass the template as build_pptx_from_pages's template. A deck the user already has stays on the PowerPoint tools above. To change a deck built from sections, edit its sections and build again.
