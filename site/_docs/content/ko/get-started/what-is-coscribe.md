Coscribe는 Windows용 AI 사무 도우미입니다. 필요한 것을 한 문장으로 말하면 스프레드시트와 문서를 읽고 완성된 파일을 만듭니다. 변경 내용 추적과 메모가 달린 계약서, 차트가 들어간 보고 프레젠테이션, 대조를 마친 Excel 통합 문서 같은 것들입니다.

오픈 소스(MIT 라이선스)이며 무료입니다. 사용자가 고른 모델 서비스 비용만 냅니다.

## 할 수 있는 일 {#what-it-can-do}

- **Excel**: 데이터를 읽고, 정리하고, 요약하고, 대조합니다. 수식과 차트를 작성합니다.
- **Word**: 문서를 작성하고 수정하며, 다른 사람이 검토할 수 있도록 변경 내용 추적과 메모로 변경 사항을 표시합니다.
- **PowerPoint**: 데이터와 자료를 프레젠테이션으로 만듭니다. 회사 서식 파일과 색상이 있으면 그것을 씁니다.
- **PDF**: 내용을 검색하고, 추출하고, 정리합니다.
- **웹**: 내장 브라우저에서 사이트를 열고, 양식을 채우고, 표를 저장합니다.
- **워크플로**: 대화에서 한 일을 고정된 단계로 저장해, 클릭 한 번이나 일정에 따라 다시 실행합니다.

## 다른 AI 도구와 다른 점 {#how-it-differs-from-other-ai-tools}

**파일이 내 PC에 머뭅니다.** Coscribe에는 자체 클라우드 서비스가 없습니다. 모델이 읽어야 하는 내용만 사용자가 고른 모델 공급자에게 전달되며, Ollama로 내 컴퓨터에서 모델을 실행하면 아무것도 밖으로 나가지 않습니다.

**모델은 사용자가 고릅니다.** Claude, GPT, Gemini가 기본 제공됩니다. DeepSeek, Kimi, GLM, Qwen, Doubao를 비롯해 OpenAI 호환 API를 제공하는 서비스는 주소와 API 키만 입력하면 쓸 수 있습니다. [모델 공급자 추가](providers.md)를 참고하세요.

**변경하기 전에 묻습니다.** 네 가지 권한 모드가 "매 단계마다 물어봐"부터 "일상적인 작업은 검토 모델이 대신 승인하게 해"까지 있습니다. 어떤 모드에서든 허용한 폴더에만 씁니다. [첫 대화](first-conversation.md#permission-modes)를 참고하세요.

**초안이 아니라 완성된 파일을 줍니다.** 파일을 쓴 뒤 Coscribe는 그 파일을 렌더링해 결과를 보고 레이아웃과 내용을 확인합니다. 텍스트 덩어리를 건네지 않습니다.

## 시스템 요구 사항 {#system-requirements}

- Windows 10 또는 Windows 11.
- 모델 서비스의 API 키, 또는 내 PC에서 실행 중인 Ollama나 LM Studio.

> [!NOTE]
> Coscribe는 Windows 전용입니다. 아직 Mac이나 Linux 버전은 없습니다.
