공급자를 추가했다면 홈 화면의 메시지 상자에 작업을 설명하세요.

## 작업 설명하기 {#describe-a-task}

동료에게 부탁하듯이 쓰세요. 무엇이 필요한지, 어떤 자료로, 어떤 형태로 원하는지를 적습니다. 예를 들면 다음과 같습니다.

> `3분기 주문.xlsx`에서 배송 주소가 없는 주문을 삭제하고, 공급업체별로 금액을 합산해서 결과를 새 Excel 파일로 저장해 줘.

파일을 창으로 끌어다 놓거나 메시지 상자 왼쪽 아래의 **+** 버튼을 클릭해 첨부합니다. 파일 이름만 말해도 Coscribe가 워크스페이스에서 찾습니다. <kbd>Enter</kbd>를 누르면 보내고, <kbd>Shift</kbd> + <kbd>Enter</kbd>를 누르면 줄이 바뀝니다.

## 작업 지켜보기 {#watch-it-work}

Coscribe는 먼저 자료를 읽은 다음 단계별로 작업합니다. 큰 작업은 작업 목록으로 시작하고, 각 항목은 끝나면 취소선이 그어집니다. 완성된 파일은 메시지 상자 위에 나타나며, 클릭하면 미리 볼 수 있습니다.

작업하는 동안 기다릴 필요는 없습니다.

- **요청 보태기**: 메시지 상자에 계속 입력하세요. 다음 단계에서 메모를 읽습니다.
- **중지하기**: 메시지 상자 오른쪽의 중지 버튼을 클릭합니다. 이미 끝낸 작업은 유지됩니다.

## 권한 모드 {#permission-modes}

메시지 상자 아래의 모드 버튼으로 Coscribe가 행동하기 전에 물어볼지를 정합니다.

| 모드 | 동작 |
|---|---|
| **Manual** | 모든 변경, 스크립트, 외부 작업 전에 묻습니다. |
| **Accept Edits** | 폴더 안의 파일은 묻지 않고 편집하지만, 코드 실행이나 외부 작업 전에는 여전히 묻습니다. |
| **Plan** | 조사한 뒤 계획을 작성하고, 어떤 변경이든 하기 전에 승인을 받습니다. |
| **Auto** | 검토 모델이 일상적인 작업은 승인하고 위험한 작업은 막습니다. 사용자에게 묻지 않습니다. |

승인이 필요하면 대화에 카드가 나타나 Coscribe가 하려는 일을 알려 줍니다. 읽어 본 뒤 **Approve** 또는 **Deny**를 클릭하세요.

> [!TIP]
> 처음에는 **Manual** 또는 **Plan**을 선택하세요. Coscribe가 어떻게 일하는지 알게 되면 **Accept Edits**나 **Auto**로 바꾸세요.

어떤 모드에서든 Coscribe는 워크스페이스와 사용자가 허용한 다른 폴더에만 씁니다.

## 명령과 단축키 {#commands-and-shortcuts}

메시지 상자에 <kbd>/</kbd>를 입력하면 대화 압축이나 대화 복사 같은 명령 목록이 나타납니다. <kbd>?</kbd>를 누르거나 오른쪽 위의 키보드 아이콘을 클릭하면 모든 키보드 단축키를 볼 수 있습니다.
