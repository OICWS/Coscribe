coscribe는 사용자의 PC에서 실행됩니다. 자체 계정이나 서버가 없고, 사용자나 사용 방식에 관한 어떤 정보도 개발자에게 보내지 않습니다.

## 컴퓨터 밖으로 나가는 것 {#what-leaves-your-computer}

| 보내는 곳 | 내용 | 시점 |
|---|---|---|
| 고른 모델 공급자 | 메시지, 답하기 위해 coscribe가 읽은 파일의 일부, 도구 결과 | 답변할 때마다. [내 PC의 모델](../get-started/providers.md#run-a-model-on-your-pc)을 쓰면 이것도 컴퓨터 안에 머뭅니다. |
| 검색 엔진 | 검색어 | coscribe가 웹을 검색할 때. DuckDuckGo 같은 무료 검색 엔진을 키 없이 씁니다. |
| 웹사이트 | 일반적인 페이지 요청 | 사용자가 요청했거나 작업에 필요한 페이지를 coscribe가 열 때. [내장 브라우저](../use/browser.md)를 참고하세요. |
| 연결한 서비스 | 커넥터 도구가 보내는 내용 | coscribe가 그 [커넥터](../customize/connectors.md)를 쓸 때. |

공급자가 무엇을 얼마나 오래 보관하는지는 공급자 자체 약관이 정합니다. 업무 문서를 보내기 전에 읽어 보세요.

## 데이터가 보관되는 곳 {#where-your-data-is-kept}

나머지는 모두 PC에 남습니다.

- 파일은 원래 있던 곳에 그대로 있고, coscribe는 그 자리에서 작업합니다.
- 대화, 예약 작업, 스킬, 설정은 `%APPDATA%\Coscribe` 아래에 있습니다.
- API 키와 [시크릿](../reference/settings.md#secrets)은 일반 파일이 아니라 Windows 자격 증명 관리자에 있습니다.
- 각 턴의 진행 기록(모델, 도구 호출, 오류, 토큰, 시간. 대화 내용은 제외)은 문제 해결을 위해 PC에 남습니다. 어디에도 업로드되지 않습니다.

## 작업을 통제하는 장치 {#what-keeps-actions-in-check}

- **폴더**: coscribe는 워크스페이스와 사용자가 허용한 다른 폴더에만 씁니다. [워크스페이스와 폴더](../workspaces/workspaces.md)를 참고하세요.
- **승인**: 무언가를 바꾸는 작업은 [권한 모드](../use/approvals.md)에 따라 사용자를 기다립니다. coscribe가 자체 파일 도구로 삭제한 파일은 휴지통으로 갑니다.
- **스크립트**: Windows가 허용하면 격리된 컨테이너에서 워크스페이스 폴더 범위로 실행됩니다. 격리를 설정할 수 없으면 사용자가 달리 정하지 않는 한 스크립트는 꺼집니다. [스크립트와 격리](../workspaces/workspaces.md#scripts-and-isolation)를 참고하세요.
- **사이트**: coscribe가 브라우저에서 열 수 있는 사이트는 워크스페이스의 사이트 설정을 따릅니다. [사이트 허용하기](../use/browser.md#allow-a-site)를 참고하세요.

> [!IMPORTANT]
> 승인은 사용자가 하는 확인일 뿐, 샌드박스가 아닙니다. 승인한 스크립트나 명령은 격리로 막히지 않는 한 내 Windows 계정이 할 수 있는 일을 할 수 있습니다. **Allow**를 클릭하기 전에 승인 카드의 내용을 읽어 보세요.

## 주의할 점 {#things-to-watch-for}

- 웹, 이메일, 문서의 글에는 AI를 노린 지시가 들어 있을 수 있습니다. coscribe는 읽은 내용을 사용자의 명령이 아니라 자료로 다루지만, 완벽한 모델은 없습니다. 다른 사람이 쓴 것을 읽는 작업에서는 **Never ask**와 **Auto**를 조심해서 쓰세요.
- 스킬, 플러그인, 커넥터는 신뢰하는 사람의 것만 추가하세요.
