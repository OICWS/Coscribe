## 对话做出了什么 {#what-a-conversation-made}

Coscribe 新建或修改的文件会以通知的形式出现在输入框上方：

- 文档、演示文稿或设计会在对话旁边的面板里打开。
- 图片归在同一条通知里；**View all** 在查看器里打开全部图片。
- Excel、Word、PDF 和 CSV 文件提供 **Open in its app** 和 **Show in folder**。

关掉的通知会一直关着，直到那个文件再次变化。

## Files 面板 {#the-files-panel}

工具栏里的 **Files** 显示对话用到的文件夹，工作区排在最前。点击文件即可预览：

- Markdown、HTML、SVG 和 CSV 按实际效果显示，旁边有 **View source**。
- 代码和配置文件带语法高亮。
- 图片和 PDF 直接显示。
- Office 文件可以在 **Viewer** 里打开，也可以用它自己的程序打开。

超过 2 MB 的文件不预览。在 **Filter files...** 里输入文件名可以查找文件，面板打开时也可以按 <kbd>Ctrl</kbd> + <kbd>P</kbd>。**...** 菜单还可以复制文件路径、在文件夹中显示或下载文件。

## 面板 {#panels}

对话上方的工具栏可以在旁边打开这些面板：

| 面板 | 显示什么 |
|---|---|
| **Task details** | 任务清单，以及每一步启动了什么。 |
| **Plan** | 等你确认的计划和它的步骤。 |
| **Files** | 对话的文件夹和文件预览。 |
| **Browser** | Coscribe 的内置浏览器（仅桌面应用）。见[内置浏览器](browser.md)。 |
| **Background tasks** | 仍在运行的脚本和命令，可以在这里停掉。 |
| **Side chat** | 关于这个对话、但不会成为对话一部分的提问。见[在对话里工作](conversations.md#ask-a-side-question)。 |

面板可以并排摆放，大多数还能在单独的窗口里打开。后台脚本或命令结束时，Coscribe 会自己在对话里报告结果。
