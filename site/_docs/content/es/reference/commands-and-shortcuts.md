## Comandos {#commands}

Escribe <kbd>/</kbd> en el cuadro de mensaje para ver la lista de comandos; escribe más para filtrarla, y <kbd>Enter</kbd> ejecuta el resaltado.

| Comando | Qué hace |
|---|---|
| `/compact` | Resume la conversación para liberar contexto. Consulta [Modelos, esfuerzo y contexto](../use/models.md#watch-the-context). |
| `/clear` | Archiva la conversación y empieza una nueva en el mismo espacio de trabajo. |
| `/fork [nombre]` | Copia la conversación en una nueva y la abre. Consulta [Copiar una conversación](../use/conversations.md#copy-a-conversation). |
| `/init` | Explora el espacio de trabajo y escribe o actualiza `OVERVIEW.md` en su raíz. |
| `/create-skill <nombre>` | Convierte la conversación en una habilidad reutilizable. Consulta [Habilidades y plugins](../customize/skills.md). |
| `/doctor` | Comprueba lo que coscribe necesita en este ordenador. Consulta [Solución de problemas](../help/troubleshooting.md). |
| `/<habilidad>` | Usa esa habilidad para tu petición. Cada una de tus habilidades aparece en la lista con su nombre. |

Algunos comandos no están en la lista porque un botón hace lo mismo, pero funcionan si los escribes:

| Comando | Qué hace |
|---|---|
| `/plan` | Activa el modo **Plan**, o vuelve a **Manual** si ya está activo. |
| `/accept-edits` | Activa el modo **Accept Edits**, o vuelve a **Manual**. |
| `/auto` | Activa el modo **Auto**, o vuelve a **Manual**. |
| `/stop` | Detiene la respuesta en curso. |
| `/saveworkflow [nombre]` | Redacta un flujo de trabajo a partir de la conversación. Consulta [Flujos de trabajo](../workflows/workflows.md). |

## Atajos de teclado {#keyboard-shortcuts}

Pulsa <kbd>?</kbd> en cualquier lugar fuera de un cuadro de texto, o haz clic en el icono del teclado arriba a la derecha, para ver los atajos en la aplicación.

### En todas partes {#everywhere}

| Teclas | Qué hacen |
|---|---|
| <kbd>?</kbd> | Mostrar la lista de atajos. |
| <kbd>Esc</kbd> | Cerrar un diálogo o cancelar la edición de un mensaje. |

### En el cuadro de mensaje {#in-the-message-box}

| Teclas | Qué hacen |
|---|---|
| <kbd>Enter</kbd> | Enviar el mensaje. |
| <kbd>Shift</kbd> + <kbd>Enter</kbd> o <kbd>Ctrl</kbd> + <kbd>Enter</kbd> | Empezar una línea nueva. |
| <kbd>/</kbd> | Abrir la lista de comandos. |

### En el selector de modelos {#in-the-model-picker}

| Teclas | Qué hacen |
|---|---|
| <kbd>1</kbd> a <kbd>9</kbd> | Cambiar al modelo con ese número. |

### En la aplicación de escritorio {#in-the-desktop-app}

| Teclas | Qué hacen |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>N</kbd> | Conversación nueva. |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>O</kbd> | Elegir un espacio de trabajo. |
| <kbd>Ctrl</kbd> + <kbd>,</kbd> | Abrir los ajustes. |
| <kbd>Ctrl</kbd> + <kbd>W</kbd> | Salir de la conversación y empezar una nueva. |
| <kbd>Ctrl</kbd> + <kbd>F</kbd> | Buscar en la página; <kbd>F3</kbd> y <kbd>Shift</kbd> + <kbd>F3</kbd> van a la coincidencia siguiente y a la anterior. |
| <kbd>Alt</kbd> + <kbd>←</kbd> / <kbd>Alt</kbd> + <kbd>→</kbd> | Volver a la página anterior, o avanzar de nuevo. |
| <kbd>Ctrl</kbd> + <kbd>/</kbd> | Mostrar la lista de atajos. |
