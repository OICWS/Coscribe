Coscribe не требует установки: скачайте один zip-файл, распакуйте его куда угодно и запустите. Он не меняет никаких системных настроек.

## Скачивание {#download}

1. Откройте [страницу выпуска Coscribe](https://github.com/OICWS/coscribe/releases/tag/beta) на GitHub.
2. В разделе **Assets** скачайте файл `.zip`.
3. Распакуйте его туда, где легко найти, например в `D:\coscribe`.

> [!NOTE]
> Текущий выпуск — бета-версия.

## Первый запуск {#first-start}

В распакованной папке дважды щёлкните `Coscribe.exe`.

Приложение пока не подписано цифровой подписью, поэтому при первом запуске Windows может показать синее окно «Система Windows защитила ваш компьютер». Нажмите **Подробнее**, затем **Выполнить в любом случае**. Больше этот вопрос не появится.

## Выберите рабочее пространство {#choose-a-workspace}

При первом запуске Coscribe просит выбрать **рабочее пространство** (workspace) — папку, где вы храните рабочие файлы. Он предлагает `Documents\Coscribe`; нажмите **Browse…**, чтобы выбрать другую папку, затем **Use this folder**.

Рабочее пространство делает две вещи:

- Файлы, которые создаёт Coscribe, по умолчанию сохраняются туда.
- Файлы, которые вы прикрепляете к разговору, копируются в его папку `.coscribe`.

Coscribe может читать и изменять любой файл в рабочем пространстве. Чтобы перейти в другое рабочее пространство или дать Coscribe доступ и к другим папкам, воспользуйтесь переключателем под полем сообщения или откройте **Settings › Workspaces**.
