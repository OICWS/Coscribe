Откройте настройки значком шестерёнки в правом верхнем углу или сочетанием <kbd>Ctrl</kbd> + <kbd>,</kbd> в настольном приложении. Поле поиска вверху находит настройку по названию.

## General {#general}

| Настройка | Что делает |
|---|---|
| **Theme** | Светлая, тёмная или как в Windows. |
| **Interface font** | Шрифт меню, панелей и разговоров: Figtree, системный шрифт или OpenDyslexic. |
| **Motion** | **Reduced** уменьшает анимацию в выводимых ответах и в других местах. |
| **Conversation view** | **Simple** показывает каждый ответ без стоящих за ним шагов и одну строку о том, что делает coscribe. **Detailed** показывает все шаги. |
| **What should Coscribe call you?** | Имя в приветствии на главном экране. |
| **Default model** | Модель, с которой начинается новый разговор. Каждый разговор может сменить её в своём списке моделей. |
| **Default mode** | [Режим разрешений](../get-started/first-conversation.md#permission-modes), в котором начинается новый разговор. |
| **Global instructions** | То, что coscribe должен знать всегда. См. [Инструкции](../customize/instructions.md). |
| **Prompt suggestions** | После ответа предлагает ваше следующее сообщение в поле сообщения: <kbd>Enter</kbd> отправляет его, <kbd>Tab</kbd> вставляет в поле для правки. Немного увеличивает расход. |
| **Background agents** | Позволяет coscribe передавать работу помощникам, которые работают в фоне, пока вы продолжаете разговор. Они могут расходовать много. |
| **Archive inactive conversations** | Архивирует разговоры после 7, 30 или 90 дней без активности или никогда. Открытый разговор или разговор с идущей работой никогда не архивируется. |
| **Keep running in the background** | При закрытии окна coscribe остаётся в области уведомлений, и запланированные задачи продолжают выполняться. Если выключено, закрытие окна завершает приложение. |
| **Notifications** | **All** (все запуски задач), **Problems only** (запуск не удался или ждёт вас) или **Off**. |
| **Draw attention when Coscribe needs you** | Мигает кнопкой на панели задач, когда ответ завершён или coscribe ждёт вас, а окно не на переднем плане. |
| **Keep computer awake while Coscribe works** | Не даёт ПК уйти в сон во время ответа, чтобы длинные задачи могли завершиться. Экран всё равно может погаснуть, а закрытие крышки всё равно переводит в сон. **Keep awake on battery power** делает то же при работе от батареи. |
| **Proxy** | Как coscribe выходит в интернет: **System**, **Manual** (адрес, узлы для прямого подключения, имя пользователя и пароль) или **No proxy**. |

## Workspaces {#workspaces}

Список ваших [рабочих пространств](../workspaces/workspaces.md): **New** добавляет новое, а меню **⋯** у каждого позволяет изменить или удалить его. **Allowed folders** — единый список папок вне основной папки рабочего пространства, у каждой свой уровень доступа; рабочее пространство обращается только к тем, которые выбрало. См. [Разрешённые папки](../workspaces/workspaces.md#allowed-folders).

## Providers {#providers}

Подключённые вами сервисы моделей и включённые для каждого модели. См. [Добавление поставщика моделей](../get-started/providers.md).

## Capabilities {#capabilities}

| Настройка | Что делает |
|---|---|
| **Create and edit files** | Позволяет coscribe записывать и изменять файлы в папках рабочего пространства. Если выключено, он только читает их и отвечает в разговоре. |
| **Artifacts** | Документы, дизайны и дашборды, которые открываются рядом с разговором. См. [Документы, дизайны и дашборды](../office/artifacts.md). |
| **Run scripts** | Для работы, слишком большой для встроенных инструментов, coscribe пишет скрипт на Python или Node.js и выполняет его после вашего подтверждения, в пределах папок рабочего пространства. См. [Скрипты и изоляция](../workspaces/workspaces.md#scripts-and-isolation). |
| **Run commands** | Командные строки в cmd или PowerShell — для того, что не может сделать скрипт, например git или установщик. Вы подтверждаете каждую. **Command sandbox** и **Private folders** определяют, к чему может обращаться команда. |
| **Chats can hand tasks to Code** | Позволяет разговору передать задачу программирования Codex — агенту для программирования. **Model for code** выбирает его модель; **Change files without asking** позволяет ему править файлы, не спрашивая о каждом изменении. |
| **Python for scripts**, **Packages for scripts** | Какой Python выполняет скрипты и какие дополнительные библиотеки Python и Node.js они могут использовать. |
| **LibreOffice**, **Codex** | Необязательные загрузки, которые здесь устанавливают, обновляют или удаляют. LibreOffice создаёт предпросмотр страниц. |

## Secrets {#secrets}

Ключи и токены, которые вы добавляете один раз, а затем выдаёте нужным рабочим пространствам. coscribe может использовать секрет в веб-запросе только для разрешённых вами узлов, а модель никогда не видит его значение: оно не попадает в сообщения, результаты инструментов и журналы. Секреты хранятся в диспетчере учётных данных Windows, а не в обычном файле.

> [!IMPORTANT]
> Это не даёт значению попасть в то, что читает модель. Это не защита от программы, которая станет его искать: всё, что coscribe запускает на вашем ПК, работает от вашего имени и может само прочитать хранилище учётных данных.
