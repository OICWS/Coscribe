## Команды {#commands}

Введите <kbd>/</kbd> в поле сообщения, чтобы увидеть список команд; продолжайте ввод, чтобы отфильтровать его, а <kbd>Enter</kbd> выполняет выделенную команду.

| Команда | Что делает |
|---|---|
| `/compact` | Кратко излагает разговор, чтобы освободить контекст. См. [Модели, усилие и контекст](../use/models.md#watch-the-context). |
| `/clear` | Архивирует разговор и начинает новый в том же рабочем пространстве. |
| `/fork [name]` | Копирует разговор в новый и открывает его. См. [Копирование разговора](../use/conversations.md#copy-a-conversation). |
| `/init` | Изучает рабочее пространство и записывает или обновляет `OVERVIEW.md` в его корне. |
| `/create-skill <name>` | Превращает разговор в навык для повторного использования. См. [Навыки и плагины](../customize/skills.md). |
| `/doctor` | Проверяет, что нужно coscribe на этом компьютере. См. [Устранение неполадок](../help/troubleshooting.md). |
| `/<skill>` | Использует этот навык для вашего запроса. Каждый ваш навык есть в списке под своим именем. |

Некоторых команд нет в списке, потому что то же самое делает кнопка, но при вводе они работают:

| Команда | Что делает |
|---|---|
| `/plan` | Включает режим **Plan** или возвращает в **Manual**, если он уже включён. |
| `/accept-edits` | Включает режим **Accept Edits** или возвращает в **Manual**. |
| `/auto` | Включает режим **Auto** или возвращает в **Manual**. |
| `/stop` | Останавливает текущий ответ. |
| `/saveworkflow [name]` | Готовит черновик рабочего процесса из разговора. См. [Рабочие процессы](../workflows/workflows.md). |

## Сочетания клавиш {#keyboard-shortcuts}

Нажмите <kbd>?</kbd> в любом месте вне текстового поля или значок клавиатуры в правом верхнем углу, чтобы увидеть сочетания клавиш в приложении.

### Везде {#everywhere}

| Клавиши | Что делают |
|---|---|
| <kbd>?</kbd> | Показать список сочетаний клавиш. |
| <kbd>Esc</kbd> | Закрыть диалог или отменить правку сообщения. |

### В поле сообщения {#in-the-message-box}

| Клавиши | Что делают |
|---|---|
| <kbd>Enter</kbd> | Отправить сообщение. |
| <kbd>Shift</kbd> + <kbd>Enter</kbd> или <kbd>Ctrl</kbd> + <kbd>Enter</kbd> | Начать новую строку. |
| <kbd>/</kbd> | Открыть список команд. |

### В списке моделей {#in-the-model-picker}

| Клавиши | Что делают |
|---|---|
| <kbd>1</kbd>–<kbd>9</kbd> | Переключиться на модель с этим номером. |

### В настольном приложении {#in-the-desktop-app}

| Клавиши | Что делают |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>N</kbd> | Новый разговор. |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>O</kbd> | Выбрать рабочее пространство. |
| <kbd>Ctrl</kbd> + <kbd>,</kbd> | Открыть настройки. |
| <kbd>Ctrl</kbd> + <kbd>W</kbd> | Покинуть разговор и начать новый. |
| <kbd>Ctrl</kbd> + <kbd>F</kbd> | Найти на странице; <kbd>F3</kbd> и <kbd>Shift</kbd> + <kbd>F3</kbd> переходят к следующему и предыдущему совпадению. |
| <kbd>Alt</kbd> + <kbd>←</kbd> / <kbd>Alt</kbd> + <kbd>→</kbd> | Вернуться на предыдущую страницу или снова вперёд. |
| <kbd>Ctrl</kbd> + <kbd>/</kbd> | Показать список сочетаний клавиш. |
