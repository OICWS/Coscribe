Папка может содержать инструкции для coscribe во вложенной папке `.coscribe`. coscribe читает их в любом разговоре, который использует эту папку, после того как вы их примете.

## Что может содержать папка {#what-a-folder-can-hold}

| Файл | Назначение |
|---|---|
| `.coscribe/memory.md` | Заметки, которые coscribe читает в начале каждого разговора в этой папке: для чего папка, соглашения, названия. |
| `.coscribe/skills/<name>/SKILL.md` | [Навыки](../customize/skills.md), действующие только в этой папке. |
| `.coscribe/settings.json` | Правила разрешений (`allow`, `ask`, `deny`) и переменные окружения для скриптов. |
| `.coscribe/mcp.json` | [Коннекторы](../customize/connectors.md), которые использует эта папка. |

Сам coscribe никогда не записывает `memory.md`, `settings.json` и `mcp.json`; их редактируете только вы. Отправленные вами вложения хранятся в `.coscribe/uploads/`.

## Принятие настроек папки {#accept-a-folders-settings}

Настройки папки мог записать любой, у кого есть к ней доступ на запись, поэтому coscribe не следует им, пока вы не согласитесь. Панель **Task details** показывает **What Coscribe knows about this folder**: навыки, коннекторы и правила, которые приносит папка, сгруппированные как **Runs without asking**, **Always asks** и **Never runs**, а также переменные для скриптов. Нажмите **Use them**, чтобы принять.

Если какой-либо из этих файлов изменится вне coscribe, он спросит снова.

## Правила разрешений {#permission-rules}

`.coscribe/settings.json` имеет тот же формат, что и файл настроек Claude Code:

```json
{
  "permissions": {
    "allow": ["write_file(reports/*)"],
    "ask": ["run_background_command"],
    "deny": ["delete_file"]
  },
  "env": {
    "REPORT_REGION": "East"
  }
}
```

Правило — это имя инструмента coscribe, шаблон имён со `*` или любое из них с шаблоном главного аргумента в скобках, например `write_file(docs/*)`. Правила решают только те действия, которые иначе ждали бы вашего подтверждения. **deny** важнее **ask**, а **ask** важнее **allow**.

Некоторые ограничения действуют всегда:

- Правило никогда не разрешает действие, выходящее за пределы вашего компьютера, например отправку сообщения через коннектор; такие действия по-прежнему требуют вопроса.
- Одиночный `*` ничего не разрешает.
- Правило `ask` спрашивает даже в режиме **Auto**.

## Переменные для скриптов {#variables-for-scripts}

Значения `env` из `settings.json` передаются скриптам и командам в папке. Папка не может задавать переменные, которые меняют, какие программы запускаются или куда идёт трафик, например `PATH`, настройки прокси или `PYTHONPATH`.
