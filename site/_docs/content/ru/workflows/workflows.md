Рабочий процесс — это задача из фиксированных шагов. В отличие от запланированной задачи, которая следует письменным инструкциям, рабочий процесс каждый раз выполняет одни и те же шаги и проверяет их по ходу, поэтому вы видите, что он сделает, ещё до того, как он это сделает. Расписание, разрешения и отчёты о запусках работают так же, как у [запланированных задач](scheduled-tasks.md).

## Создание рабочего процесса {#make-a-workflow}

Проще всего один раз выполнить работу в чате, а затем сделать из неё рабочий процесс:

- Выберите **Save as workflow**, когда Coscribe предложит **Save this job?**, или в панели **Task details**.
- Или введите `/saveworkflow` в поле сообщения, при желании с названием.

Coscribe готовит черновик шагов из разговора. Просмотрите их и сохраните.

Можно начать и с нуля: **Scheduled** › **New task** › **Build a workflow**. Задайте название и расписание, сохраните, а затем добавьте шаги на его странице.

## Страница рабочего процесса {#the-workflow-page}

На странице четыре вкладки:

- **Overview** простыми словами описывает, что делает рабочий процесс: когда он запускается, с чем работает, где останавливается и ждёт вас и что может затрагивать. **Show the flowchart** рисует шаги.
- **Steps** перечисляет шаги; здесь их добавляют, меняют и переставляют. Вид можно переключить на **Flowchart**.
- **Runs** перечисляет прошлые запуски.
- **Settings** содержит расписание, рабочее пространство и разрешения.

**Run now** неактивна, пока в рабочем процессе нет шагов. Если рабочий процесс принимает входные данные, например файл, он сначала запросит их.

## Виды шагов {#kinds-of-steps}

**Add a step** предлагает такие виды:

| Шаг | Что делает |
|---|---|
| **Tool** | Использует один из инструментов Coscribe без участия модели. |
| **Script** | Выполняет фиксированный скрипт Python, который вы проверили. |
| **Model** | Одно обращение к модели, которое должно вернуть заданные поля. |
| **Agent** | Добивается цели с помощью инструментов в заданных вами пределах: какие инструменты можно вызывать, какие папки менять и какие сайты открывать. |
| **Check** | Останавливает запуск, если значения не соответствуют условиям. |
| **Approval** | Ждёт, пока вы не подтвердите. |
| **Ask you** | Ждёт, пока вы не заполните значения, которые используют следующие шаги. |
| **Wait** | Ждёт какое-то время, до определённого момента или пока не появится файл. |
| **Remember** | Сохраняет значение для следующего запуска, например что уже обработано. |
| **Run a task** | Выполняет другую вашу задачу как один шаг и использует её результаты. |
| **If / otherwise** | Выполняет разные шаги в зависимости от значения. |
| **Choose a path** | Несколько путей, выбираемых по значению. |
| **At the same time** | Выполняет одновременно от 2 до 6 дорожек шагов, затем продолжает. |
| **For each** | Повторяет шаги для каждого элемента списка. |

Для каждого шага можно выбрать, что происходит при ошибке: **Stop the run**, **Skip it and go on** или **Run other steps instead**. Шаг также может повторять попытку заданное число раз.

## Когда шаг перестаёт работать {#autonomy}

Сайты меняются, а файлы от запуска к запуску различаются. Параметр **If a step stops working** определяет, сколько может решать ИИ, когда это происходит:

| Уровень | Что происходит |
|---|---|
| **Fixed** | Выполняются только сохранённые шаги. Если какой-то не удался, запуск останавливается и сообщает вам. |
| **Self-healing** | Если сайт изменился, ИИ выполняет этот шаг на странице в её нынешнем виде. |
| **Proactive** | Шаги ИИ сами решают, как сделать свою часть. Если шаг не удался, ИИ может добавить несколько шагов; те, что что-то меняют, ждут вас. |
| **Autonomous** | ИИ может выполнить всю задачу по-своему. |

Когда запуск обошёл изменение, Coscribe может предложить обновлённые шаги для проверки, чтобы следующему запуску не пришлось его обходить.

## Запуск рабочего процесса по событию {#start-on-an-event}

Помимо расписаний, общих для всех задач, **Frequency** рабочего процесса может быть:

- **Every few minutes**.
- **When a file arrives in a folder**: выберите **Folder to watch** и при желании **File name pattern**. Каждый новый файл запускает рабочий процесс, и файл становится его входным файлом. Вариант доступен для рабочего процесса, который принимает файл.
- **When something new shows up in a connector**: выберите коннектор и что у него запрашивать. Coscribe опрашивает его каждые несколько минут, и каждый новый элемент запускает рабочий процесс. При первой проверке всё, что уже есть, считается просмотренным.
- **When a program sends it an event**: другая программа на том же компьютере отправляет запрос с ключом на адрес, который показывает Coscribe. **Wait for a sample** сохраняет следующее событие, чтобы вы выбрали, какие его поля заполняют входные данные. Адрес принимает запросы только с вашего компьютера.

Файл, пришедший, пока Coscribe был закрыт, запускает рабочий процесс при следующем запуске Coscribe.
