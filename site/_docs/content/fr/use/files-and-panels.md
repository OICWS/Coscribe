## Ce qu’une conversation a créé {#what-a-conversation-made}

Les fichiers que coscribe a créés ou modifiés apparaissent sous forme d’avis au-dessus de la zone de message :

- Un document, une présentation ou un design s’ouvre dans son panneau, à côté de la conversation.
- Les images sont regroupées dans un seul avis ; **View all** les ouvre dans une visionneuse.
- Les fichiers Excel, Word, PDF et CSV proposent **Open in its app** et **Show in folder**.

Un avis fermé reste fermé jusqu’à ce que ce fichier change à nouveau.

## Le panneau Files {#the-files-panel}

**Files**, dans la barre d’outils, affiche les dossiers de la conversation, l’espace de travail en premier. Cliquez sur un fichier pour le prévisualiser :

- Markdown, HTML, SVG et CSV s’affichent tels qu’ils apparaissent, avec **View source** à côté.
- Les fichiers de code et de configuration s’affichent avec coloration syntaxique.
- Les images et les fichiers PDF s’affichent directement.
- Les fichiers Office peuvent s’ouvrir dans le **Viewer** ou dans leur propre application.

Les fichiers de plus de 2 Mo ne sont pas prévisualisés. Tapez dans **Filter files...** pour trouver un fichier par son nom, ou appuyez sur <kbd>Ctrl</kbd> + <kbd>P</kbd> quand le panneau est ouvert. Le menu **...** permet aussi de copier le chemin d’un fichier, de l’afficher dans son dossier ou de le télécharger.

## Panneaux {#panels}

La barre d’outils au-dessus de la conversation ouvre des panneaux à côté :

| Panneau | Ce qu’il affiche |
|---|---|
| **Task details** | La liste de tâches et ce que chaque étape a lancé. |
| **Plan** | Un plan qui vous attend, et ses étapes. |
| **Files** | Les dossiers de la conversation et les aperçus de fichiers. |
| **Browser** | Le navigateur intégré de coscribe (application de bureau uniquement). Voir [Le navigateur intégré](browser.md). |
| **Background tasks** | Les scripts et commandes encore en cours, que vous pouvez arrêter. |
| **Side chat** | Des questions sur la conversation qui n’en font pas partie. Voir [Travailler dans une conversation](conversations.md#ask-a-side-question). |

Les panneaux peuvent être placés côte à côte, et la plupart peuvent aussi s’ouvrir dans leur propre fenêtre. Quand un script ou une commande en arrière-plan se termine, coscribe indique de lui-même dans la conversation comment cela s’est terminé.
