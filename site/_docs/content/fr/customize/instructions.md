---
title: Instructions
description: Dites une fois à Coscribe ce qu’il doit toujours savoir, pour toutes les conversations ou pour un dossier.
---

Les instructions sont des notes permanentes que Coscribe lit avant de traiter votre demande, pour que vous n’ayez pas à les répéter.

## Pour toutes les conversations {#for-every-conversation}

Ouvrez **Settings** › **General** et écrivez dans **Global instructions** les préférences, conventions ou éléments de contexte que Coscribe doit toujours connaître. Par exemple, le nom de votre entreprise, le format de date que vous utilisez ou le fait que les rapports sont rédigés en anglais. Elles s’appliquent à chaque nouvelle conversation, et vous seul pouvez les modifier ; Coscribe ne peut pas les changer lui-même.

## Pour un dossier {#for-one-folder}

Écrivez des notes pour un dossier dans `.coscribe/memory.md`, à l’intérieur de celui-ci : à quoi sert le dossier, ses conventions, les noms qui y sont utilisés. Coscribe les lit au début de chaque conversation dans ce dossier, une fois que vous avez accepté les paramètres du dossier. Voir [Notes et règles propres à un dossier](../workspaces/folder-settings.md).

## Faire décrire un dossier par Coscribe {#have-coscribe-describe-a-folder}

Tapez `/init` dans une conversation : Coscribe explore l’espace de travail et écrit `OVERVIEW.md` à sa racine, avec ce que contient le dossier et comment il est organisé. Relancez la commande plus tard pour mettre le fichier à jour.

## Votre nom {#your-name}

**What should Coscribe call you?**, dans **Settings** › **General**, définit le nom utilisé dans le message d’accueil de l’écran d’accueil.
