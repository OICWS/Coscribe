## Commandes {#commands}

Tapez <kbd>/</kbd> dans la zone de message pour afficher la liste des commandes ; continuez à taper pour la filtrer, et <kbd>Enter</kbd> exécute celle qui est en surbrillance.

| Commande | Ce qu’elle fait |
|---|---|
| `/compact` | Résume la conversation pour libérer du contexte. Voir [Modèles, effort et contexte](../use/models.md#watch-the-context). |
| `/clear` | Archive la conversation et en démarre une nouvelle dans le même espace de travail. |
| `/fork [name]` | Copie la conversation dans une nouvelle et l’ouvre. Voir [Copier une conversation](../use/conversations.md#copy-a-conversation). |
| `/init` | Explore l’espace de travail et écrit ou met à jour `OVERVIEW.md` à sa racine. |
| `/create-skill <name>` | Transforme la conversation en compétence réutilisable. Voir [Compétences et plugins](../customize/skills.md). |
| `/doctor` | Vérifie ce dont Coscribe a besoin sur cet ordinateur. Voir [Dépannage](../help/troubleshooting.md). |
| `/<skill>` | Utilise cette compétence pour votre demande. Chacune de vos compétences figure dans la liste sous son nom. |

Quelques commandes ne figurent pas dans la liste parce qu’un bouton fait la même chose, mais elles fonctionnent si vous les tapez :

| Commande | Ce qu’elle fait |
|---|---|
| `/plan` | Active le mode **Plan**, ou revient à **Manual** s’il est déjà actif. |
| `/accept-edits` | Active le mode **Accept Edits**, ou revient à **Manual**. |
| `/auto` | Active le mode **Auto**, ou revient à **Manual**. |
| `/stop` | Arrête la réponse en cours. |
| `/saveworkflow [name]` | Prépare un workflow à partir de la conversation. Voir [Workflows](../workflows/workflows.md). |

## Raccourcis clavier {#keyboard-shortcuts}

Appuyez sur <kbd>?</kbd> n’importe où hors d’une zone de texte, ou cliquez sur l’icône de clavier en haut à droite, pour voir les raccourcis dans l’application.

### Partout {#everywhere}

| Touches | Action |
|---|---|
| <kbd>?</kbd> | Afficher la liste des raccourcis. |
| <kbd>Esc</kbd> | Fermer une boîte de dialogue, ou annuler la modification d’un message. |

### Dans la zone de message {#in-the-message-box}

| Touches | Action |
|---|---|
| <kbd>Enter</kbd> | Envoyer le message. |
| <kbd>Shift</kbd> + <kbd>Enter</kbd> ou <kbd>Ctrl</kbd> + <kbd>Enter</kbd> | Aller à la ligne. |
| <kbd>/</kbd> | Ouvrir la liste des commandes. |

### Dans le sélecteur de modèle {#in-the-model-picker}

| Touches | Action |
|---|---|
| <kbd>1</kbd> à <kbd>9</kbd> | Passer au modèle portant ce numéro. |

### Dans l’application de bureau {#in-the-desktop-app}

| Touches | Action |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>N</kbd> | Nouvelle conversation. |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>O</kbd> | Choisir un espace de travail. |
| <kbd>Ctrl</kbd> + <kbd>,</kbd> | Ouvrir les paramètres. |
| <kbd>Ctrl</kbd> + <kbd>W</kbd> | Quitter la conversation et en démarrer une nouvelle. |
| <kbd>Ctrl</kbd> + <kbd>F</kbd> | Rechercher dans la page ; <kbd>F3</kbd> et <kbd>Shift</kbd> + <kbd>F3</kbd> passent à l’occurrence suivante et précédente. |
| <kbd>Alt</kbd> + <kbd>←</kbd> / <kbd>Alt</kbd> + <kbd>→</kbd> | Revenir à la page précédente, ou avancer à nouveau. |
| <kbd>Ctrl</kbd> + <kbd>/</kbd> | Afficher la liste des raccourcis. |
