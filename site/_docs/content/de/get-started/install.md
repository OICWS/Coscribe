Coscribe braucht keine Installation: Laden Sie eine ZIP-Datei herunter, entpacken Sie sie an einem beliebigen Ort und starten Sie sie. Es ändert keine Systemeinstellungen.

## Download {#download}

1. Öffnen Sie die [Release-Seite von Coscribe](https://github.com/OICWS/coscribe/releases/tag/beta) auf GitHub.
2. Laden Sie unter **Assets** die `.zip`-Datei herunter.
3. Entpacken Sie sie an einem leicht auffindbaren Ort, etwa `D:\coscribe`.

> [!NOTE]
> Die aktuelle Version ist eine Beta.

## Erster Start {#first-start}

Doppelklicken Sie im entpackten Ordner auf `Coscribe.exe`.

Die App ist noch nicht codesigniert, daher zeigt Windows beim ersten Öffnen möglicherweise die blaue Meldung „Der Computer wurde durch Windows geschützt“. Klicken Sie auf **Weitere Informationen** und dann auf **Trotzdem ausführen**. Die Meldung erscheint danach nicht mehr.

## Einen Arbeitsbereich wählen {#choose-a-workspace}

Beim ersten Start bittet Coscribe Sie, einen **Arbeitsbereich** (Workspace) zu wählen: den Ordner, in dem Sie Ihre Arbeitsdateien aufbewahren. Es schlägt `Documents\Coscribe` vor; klicken Sie auf **Browse…**, um einen anderen Ordner zu wählen, und dann auf **Use this folder**.

Der Arbeitsbereich hat zwei Aufgaben:

- Dateien, die Coscribe erstellt, werden standardmäßig dort gespeichert.
- Dateien, die Sie an eine Unterhaltung anhängen, werden in seinen `.coscribe`-Ordner kopiert.

Coscribe kann jede Datei im Arbeitsbereich lesen und ändern. Um zu einem anderen Arbeitsbereich zu wechseln oder Coscribe auch andere Ordner zugänglich zu machen, verwenden Sie die Auswahl unter dem Nachrichtenfeld oder gehen Sie zu **Settings › Workspaces**.
