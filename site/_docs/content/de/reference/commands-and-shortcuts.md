## Befehle {#commands}

Tippen Sie <kbd>/</kbd> ins Nachrichtenfeld, um die Befehlsliste zu sehen; tippen Sie weiter, um sie zu filtern, und <kbd>Enter</kbd> führt den hervorgehobenen Befehl aus.

| Befehl | Was er tut |
|---|---|
| `/compact` | Fasst die Unterhaltung zusammen, um Kontext freizugeben. Siehe [Modelle, Aufwand und Kontext](../use/models.md#watch-the-context). |
| `/clear` | Archiviert die Unterhaltung und beginnt eine neue im selben Arbeitsbereich. |
| `/fork [name]` | Kopiert die Unterhaltung in eine neue und öffnet sie. Siehe [Eine Unterhaltung kopieren](../use/conversations.md#copy-a-conversation). |
| `/init` | Erkundet den Arbeitsbereich und schreibt oder aktualisiert `OVERVIEW.md` in dessen Stammordner. |
| `/create-skill <name>` | Macht aus der Unterhaltung einen wiederverwendbaren Skill. Siehe [Skills und Plugins](../customize/skills.md). |
| `/doctor` | Prüft, was Coscribe auf diesem Computer braucht. Siehe [Fehlerbehebung](../help/troubleshooting.md). |
| `/<skill>` | Verwendet diesen Skill für Ihre Anfrage. Jeder Ihrer Skills steht unter seinem Namen in der Liste. |

Einige Befehle stehen nicht in der Liste, weil eine Schaltfläche dasselbe tut, aber sie funktionieren, wenn Sie sie tippen:

| Befehl | Was er tut |
|---|---|
| `/plan` | Schaltet den Modus **Plan** ein, oder zurück zu **Manual**, wenn er an ist. |
| `/accept-edits` | Schaltet den Modus **Accept Edits** ein, oder zurück zu **Manual**. |
| `/auto` | Schaltet den Modus **Auto** ein, oder zurück zu **Manual**. |
| `/stop` | Hält die laufende Antwort an. |
| `/saveworkflow [name]` | Entwirft einen Workflow aus der Unterhaltung. Siehe [Workflows](../workflows/workflows.md). |

## Tastenkombinationen {#keyboard-shortcuts}

Drücken Sie <kbd>?</kbd> irgendwo außerhalb eines Textfelds, oder klicken Sie oben rechts auf das Tastatursymbol, um die Tastenkombinationen in der App zu sehen.

### Überall {#everywhere}

| Tasten | Was sie tun |
|---|---|
| <kbd>?</kbd> | Die Liste der Tastenkombinationen anzeigen. |
| <kbd>Esc</kbd> | Einen Dialog schließen oder das Bearbeiten einer Nachricht abbrechen. |

### Im Nachrichtenfeld {#in-the-message-box}

| Tasten | Was sie tun |
|---|---|
| <kbd>Enter</kbd> | Die Nachricht senden. |
| <kbd>Shift</kbd> + <kbd>Enter</kbd> oder <kbd>Ctrl</kbd> + <kbd>Enter</kbd> | Eine neue Zeile beginnen. |
| <kbd>/</kbd> | Die Befehlsliste öffnen. |

### In der Modellauswahl {#in-the-model-picker}

| Tasten | Was sie tun |
|---|---|
| <kbd>1</kbd> bis <kbd>9</kbd> | Zum Modell mit dieser Nummer wechseln. |

### In der Desktop-App {#in-the-desktop-app}

| Tasten | Was sie tun |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>N</kbd> | Neue Unterhaltung. |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>O</kbd> | Einen Arbeitsbereich wählen. |
| <kbd>Ctrl</kbd> + <kbd>,</kbd> | Die Einstellungen öffnen. |
| <kbd>Ctrl</kbd> + <kbd>W</kbd> | Die Unterhaltung verlassen und eine neue beginnen. |
| <kbd>Ctrl</kbd> + <kbd>F</kbd> | Auf der Seite suchen; <kbd>F3</kbd> und <kbd>Shift</kbd> + <kbd>F3</kbd> springen zum nächsten und vorherigen Treffer. |
| <kbd>Alt</kbd> + <kbd>←</kbd> / <kbd>Alt</kbd> + <kbd>→</kbd> | Zurück zur vorherigen Seite oder wieder vor. |
| <kbd>Ctrl</kbd> + <kbd>/</kbd> | Die Liste der Tastenkombinationen anzeigen. |
