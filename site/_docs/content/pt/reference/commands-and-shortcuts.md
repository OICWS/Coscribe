## Comandos {#commands}

Digite <kbd>/</kbd> na caixa de mensagem para ver a lista de comandos; continue digitando para filtrá-la, e <kbd>Enter</kbd> executa o destacado.

| Comando | O que faz |
|---|---|
| `/compact` | Resume a conversa para liberar contexto. Veja [Modelos, esforço e contexto](../use/models.md#watch-the-context). |
| `/clear` | Arquiva a conversa e começa uma nova no mesmo espaço de trabalho. |
| `/fork [name]` | Copia a conversa para uma nova e a abre. Veja [Copiar uma conversa](../use/conversations.md#copy-a-conversation). |
| `/init` | Explora o espaço de trabalho e escreve ou atualiza `OVERVIEW.md` na raiz dele. |
| `/create-skill <name>` | Transforma a conversa em uma habilidade reutilizável. Veja [Habilidades e plugins](../customize/skills.md). |
| `/doctor` | Verifica o que o Coscribe precisa neste computador. Veja [Solução de problemas](../help/troubleshooting.md). |
| `/<skill>` | Usa essa habilidade no seu pedido. Cada uma das suas habilidades está na lista com o próprio nome. |

Alguns comandos não estão na lista porque um botão faz o mesmo, mas funcionam quando digitados:

| Comando | O que faz |
|---|---|
| `/plan` | Ativa o modo **Plan**, ou volta para **Manual** se ele estiver ativo. |
| `/accept-edits` | Ativa o modo **Accept Edits**, ou volta para **Manual**. |
| `/auto` | Ativa o modo **Auto**, ou volta para **Manual**. |
| `/stop` | Para a resposta em andamento. |
| `/saveworkflow [name]` | Rascunha um fluxo de trabalho a partir da conversa. Veja [Fluxos de trabalho](../workflows/workflows.md). |

## Atalhos de teclado {#keyboard-shortcuts}

Pressione <kbd>?</kbd> em qualquer lugar fora de uma caixa de texto, ou clique no ícone de teclado no canto superior direito, para ver os atalhos no app.

### Em qualquer lugar {#everywhere}

| Teclas | O que fazem |
|---|---|
| <kbd>?</kbd> | Mostram a lista de atalhos. |
| <kbd>Esc</kbd> | Fecham uma caixa de diálogo ou cancelam a edição de uma mensagem. |

### Na caixa de mensagem {#in-the-message-box}

| Teclas | O que fazem |
|---|---|
| <kbd>Enter</kbd> | Enviam a mensagem. |
| <kbd>Shift</kbd> + <kbd>Enter</kbd> ou <kbd>Ctrl</kbd> + <kbd>Enter</kbd> | Começam uma nova linha. |
| <kbd>/</kbd> | Abrem a lista de comandos. |

### No seletor de modelos {#in-the-model-picker}

| Teclas | O que fazem |
|---|---|
| <kbd>1</kbd> a <kbd>9</kbd> | Trocam para o modelo com aquele número. |

### No app para desktop {#in-the-desktop-app}

| Teclas | O que fazem |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>N</kbd> | Nova conversa. |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>O</kbd> | Escolher um espaço de trabalho. |
| <kbd>Ctrl</kbd> + <kbd>,</kbd> | Abrir as configurações. |
| <kbd>Ctrl</kbd> + <kbd>W</kbd> | Sair da conversa e começar uma nova. |
| <kbd>Ctrl</kbd> + <kbd>F</kbd> | Localizar na página; <kbd>F3</kbd> e <kbd>Shift</kbd> + <kbd>F3</kbd> vão para a ocorrência seguinte e a anterior. |
| <kbd>Alt</kbd> + <kbd>←</kbd> / <kbd>Alt</kbd> + <kbd>→</kbd> | Voltar à página anterior ou avançar de novo. |
| <kbd>Ctrl</kbd> + <kbd>/</kbd> | Mostrar a lista de atalhos. |
