## Read and search

Coscribe reads PDFs page by page and can search one for a word or phrase, which helps with long contracts, tenders and reports. Ask it to summarize, compare two versions, or pull figures into a spreadsheet.

## Save as PDF

Coscribe can write a PDF directly, or convert a Word, Excel or PowerPoint file to PDF. For conversion it uses Microsoft Office or WPS on your computer, and LibreOffice when neither is there.

## From a web page

In the [built-in browser](../use/browser.md), Coscribe can save a web page as a PDF.
