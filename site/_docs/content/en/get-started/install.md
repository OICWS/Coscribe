coscribe needs no installation: download one zip file, unzip it anywhere and run it. It changes no system settings.

## Download

1. Open the [coscribe release page](https://github.com/OICWS/coscribe/releases/tag/beta) on GitHub.
2. Under **Assets**, download the `.zip` file.
3. Unzip it somewhere easy to find, such as `D:\coscribe`.

> [!NOTE]
> The current release is a beta.

## First start

In the unzipped folder, double-click `Coscribe.exe`.

The app is not code-signed yet, so the first time you open it Windows may show a blue "Windows protected your PC" message. Click **More info**, then **Run anyway**. It won't ask again.

## Choose a workspace

On the first start, coscribe asks you to choose a **workspace**: the folder where you keep your work files. It suggests `Documents\Coscribe`; click **Browse…** to pick another folder, then click **Use this folder**.

The workspace does two things:

- Files coscribe makes are saved there by default.
- Files you attach to a conversation are copied into its `.coscribe` folder.

coscribe can read and change every file in the workspace. To switch to another workspace, or to let coscribe reach other folders too, use the picker below the message box or go to **Settings › Workspaces**.
