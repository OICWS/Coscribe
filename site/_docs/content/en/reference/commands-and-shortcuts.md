## Commands

Type <kbd>/</kbd> in the message box for the list of commands; type more to filter it, and <kbd>Enter</kbd> runs the highlighted one.

| Command | What it does |
|---|---|
| `/compact` | Summarizes the conversation to free up context. See [Models, effort and context](../use/models.md#watch-the-context). |
| `/clear` | Archives the conversation and starts a new one in the same workspace. |
| `/fork [name]` | Copies the conversation into a new one and opens it. See [Copy a conversation](../use/conversations.md#copy-a-conversation). |
| `/init` | Explores the workspace and writes or refreshes `OVERVIEW.md` at its root. |
| `/create-skill <name>` | Turns the conversation into a reusable skill. See [Skills and plugins](../customize/skills.md). |
| `/doctor` | Checks what Coscribe needs on this computer. See [Troubleshooting](../help/troubleshooting.md). |
| `/<skill>` | Uses that skill for your request. Each of your skills is in the list under its name. |

A few commands aren't in the list because a button does the same, but they work when typed:

| Command | What it does |
|---|---|
| `/plan` | Turns **Plan** mode on, or back to **Manual** if it is on. |
| `/accept-edits` | Turns **Accept Edits** mode on, or back to **Manual**. |
| `/auto` | Turns **Auto** mode on, or back to **Manual**. |
| `/stop` | Stops the running reply. |
| `/saveworkflow [name]` | Drafts a workflow from the conversation. See [Workflows](../workflows/workflows.md). |

## Keyboard shortcuts

Press <kbd>?</kbd> anywhere outside a text box, or click the keyboard icon at the top right, to see the shortcuts in the app.

### Everywhere

| Keys | What they do |
|---|---|
| <kbd>?</kbd> | Show the shortcuts list. |
| <kbd>Esc</kbd> | Close a dialog, or cancel editing a message. |

### In the message box

| Keys | What they do |
|---|---|
| <kbd>Enter</kbd> | Send the message. |
| <kbd>Shift</kbd> + <kbd>Enter</kbd> or <kbd>Ctrl</kbd> + <kbd>Enter</kbd> | Start a new line. |
| <kbd>/</kbd> | Open the command list. |

### In the model picker

| Keys | What they do |
|---|---|
| <kbd>1</kbd> to <kbd>9</kbd> | Switch to the model with that number. |

### In the desktop app

| Keys | What they do |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>N</kbd> | New conversation. |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>O</kbd> | Choose a workspace. |
| <kbd>Ctrl</kbd> + <kbd>,</kbd> | Open settings. |
| <kbd>Ctrl</kbd> + <kbd>W</kbd> | Leave the conversation and start a new one. |
| <kbd>Ctrl</kbd> + <kbd>F</kbd> | Find in the page; <kbd>F3</kbd> and <kbd>Shift</kbd> + <kbd>F3</kbd> go to the next and previous match. |
| <kbd>Alt</kbd> + <kbd>←</kbd> / <kbd>Alt</kbd> + <kbd>→</kbd> | Back to the previous page, or forward again. |
| <kbd>Ctrl</kbd> + <kbd>/</kbd> | Show the shortcuts list. |
