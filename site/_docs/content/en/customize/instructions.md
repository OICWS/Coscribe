---
title: Instructions
description: Tell Coscribe once what it should always know, for every conversation or for one folder.
---

Instructions are standing notes that Coscribe reads before it starts on your request, so you don't have to repeat them.

## For every conversation

Open **Settings** › **General** and write in **Global instructions**: preferences, conventions or context Coscribe should always know. For example, the name of your company, the date format you use, or that reports go in English. They apply to every new conversation, and only you can change them; Coscribe can't edit them itself.

## For one folder

Write notes for one folder in `.coscribe/memory.md` inside it: what the folder is for, its conventions, the names used there. Coscribe reads them at the start of each conversation in that folder, once you've accepted the folder's settings. See [A folder's own notes and rules](../workspaces/folder-settings.md).

## Have Coscribe describe a folder

Type `/init` in a conversation, and Coscribe explores the workspace and writes `OVERVIEW.md` at its root: what the folder holds and how it is laid out. Run it again later to refresh the file.

## Your name

**What should Coscribe call you?** in **Settings** › **General** sets the name used in the greeting on the home screen.
