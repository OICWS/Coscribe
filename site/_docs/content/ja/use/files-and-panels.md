## 会話で作られたもの {#what-a-conversation-made}

Coscribe が作ったり変えたりしたファイルは、メッセージ欄の上に通知として表示されます。

- 文書、プレゼンテーション、デザインは、会話の横のパネルで開きます。
- 画像は 1 つの通知にまとめられます。**View all** でビューアーに表示します。
- Excel、Word、PDF、CSV のファイルには **Open in its app** と **Show in folder** があります。

閉じた通知は、そのファイルがまた変わるまで閉じたままです。

## Files パネル {#the-files-panel}

ツールバーの **Files** は、会話のフォルダーをワークスペースから順に表示します。ファイルをクリックするとプレビューできます。

- Markdown、HTML、SVG、CSV は見た目どおりに表示され、横に **View source** があります。
- コードや設定ファイルはハイライト付きで表示されます。
- 画像と PDF はそのまま表示されます。
- Office ファイルは **Viewer** か、それぞれのアプリで開けます。

2 MB を超えるファイルはプレビューされません。**Filter files...** に入力すると名前でファイルを探せます。パネルを開いているときは <kbd>Ctrl</kbd> + <kbd>P</kbd> でも探せます。**...** メニューから、ファイルのパスのコピー、フォルダーでの表示、ダウンロードもできます。

## パネル {#panels}

会話の上のツールバーから、横にパネルを開けます。

| パネル | 表示する内容 |
|---|---|
| **Task details** | タスクリストと、各手順が始めたこと。 |
| **Plan** | 待っている計画とその手順。 |
| **Files** | 会話のフォルダーとファイルのプレビュー。 |
| **Browser** | Coscribe の内蔵ブラウザー（デスクトップアプリのみ）。[内蔵ブラウザー](browser.md) を参照してください。 |
| **Background tasks** | まだ動いているスクリプトとコマンド。ここで止められます。 |
| **Side chat** | 会話について質問しても、会話の一部にはなりません。[会話で作業する](conversations.md#ask-a-side-question) を参照してください。 |

パネルは横に並べられ、ほとんどは別ウィンドウでも開けます。バックグラウンドのスクリプトやコマンドが終わると、Coscribe は会話でどう終わったかを自分から報告します。
