---
title: 承認と権限モード
description: coscribe が自分でどこまでしてよいかを決め、必要なときに表示されるカードに答えます。
---

coscribe は、許可なく範囲外のことはしません。どれくらい確認するかは会話の権限モードで、そもそも何に触れられるかは [ワークスペース](../workspaces/workspaces.md) で決まります。

## 4 つのモード {#the-four-modes}

メッセージ欄の下のモードボタンで選びます。新しい会話の既定は **Settings › General › Default mode** で設定します。

| モード | 動き |
|---|---|
| **Manual** | 変更、スクリプト、外部への操作の前に毎回確認します。 |
| **Accept Edits** | フォルダー内のファイルは確認なしで編集します。コードの実行や外部への操作の前には確認します。 |
| **Plan** | 調べて計画を書き、承認を得てから変更します。[計画とタスクリスト](plans.md) を参照してください。 |
| **Auto** | レビュー用のモデルが定型の操作を承認し、危険な操作を止めます。あなたには確認しません。 |

返答の実行中にモードを切り替えると、返答が終わったときに新しいモードが有効になります。

## 操作を承認する {#approve-an-action}

承認が必要になると、会話にカードが表示されます。「Run a command」のように操作の名前と、何をするか（書き込むファイル、スクリプト、コマンド）が示されます。読んでから選びます。

- **Approve** はこの操作 1 回を許可します。
- **Allow for this task**（コードモジュールのコマンドと変更でのみ表示）は、タスクの残りの間、同じ種類の操作を確認なしで許可します。
- **Deny** は拒否します。理由を伝えたいときは、代わりにメッセージ欄に書きます。coscribe が読んで調整します。

カードが画面の外に流れた場合は、メッセージ欄の上に待っているものがあると表示されます。**Show** でカードに戻れます。

> [!IMPORTANT]
> スクリプトのカードには実行方法が書かれています。通常、スクリプトは分離された状態で動きます。会話のフォルダーしか使えず、そこでファイルを削除したり名前を変えたりできず、インターネットに出られるのはワークスペースの **Sites** が **Any site** のときだけです。**Not isolated** のバッジは、その分離なしで動き、あなたが触れられるすべてのファイルに触れられることを意味します。バッジにマウスを重ねると理由が表示されます。承認する前にスクリプトを読んでください。

## ほかのフォルダーへのアクセスを許可する {#give-access-to-another-folder}

ワークスペースや許可済みのフォルダー以外のフォルダーが必要になると、coscribe はカードで尋ねます。アクセス権（**Read only**、**Read and write**、**Read, write and delete**）を選び、次から選びます。

- **Allow** はそのフォルダーを許可済みフォルダーに恒久的に追加します。
- **Only this chat** はこの会話だけで許可します。
- **Save in my workspace instead**（書き込もうとしていた場合）は、ファイルをワークスペースに保存します。
- **Don't allow** は拒否します。

coscribe がドライブ全体やユーザーのホームフォルダーを求めることはありません。

## スクリプト用のパッケージをインストールする {#install-a-package-for-a-script}

スクリプトが、coscribe にまだない Python や Node.js のライブラリを必要とすることがあります。**Install a Python package**（または Node.js）のカードが、ライブラリ名と理由を示します。**Install** は coscribe 専用の環境にインストールし、PC のほかの部分は影響を受けません。**Not now** はこの会話では入れないという返事です。インストールに失敗したら、**Details** でインストーラーの出力を確認できます。

## 質問に答える {#answer-a-question}

coscribe が、たとえば 2 つのレイアウトのどちらにするかなど、選択を求めることがあります。カードで選ぶか、メッセージ欄に自分の答えを書きます。
