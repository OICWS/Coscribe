title: coscribe とは
description: PC 上で動き、編集できる Word、Excel、PowerPoint ファイルを作るオフィスアシスタント。
---

coscribe は Windows 向けの AI オフィスアシスタントです。必要なことを一文で伝えると、スプレッドシートや文書を読んで、完成したファイルを作ります。変更履歴とコメント付きの契約書、グラフ入りの報告資料、照合済みの Excel ブックなどです。

オープンソース（MIT ライセンス）で、無料で使えます。費用がかかるのは、自分で選んだモデルサービスの利用料だけです。

## できること {#what-it-can-do}

- **Excel**：データの読み込み、整理、集計、突き合わせ。数式とグラフの作成。
- **Word**：文書の作成と修正。変更履歴とコメントで変更を示し、他の人が確認できるようにします。
- **PowerPoint**：データや資料をプレゼンテーションに。会社のテンプレートや色があれば使います。
- **PDF**：検索、抽出、内容の整理。
- **Web**：内蔵ブラウザーでサイトを開き、フォームに入力し、表を保存します。
- **ワークフロー**：会話でやったことを固定の手順として保存し、ワンクリックや決まった時刻に再実行します。

## ほかの AI ツールとの違い {#how-it-differs-from-other-ai-tools}

**ファイルは PC に残ります。** coscribe には独自のクラウドサービスがありません。モデルが読む必要のある内容だけが、選んだモデルプロバイダーに送られます。Ollama で自分の PC 上のモデルを使えば、何も外に出ません。

**モデルを選べます。** Claude、GPT、Gemini は組み込み済みです。DeepSeek、Kimi、GLM、Qwen、Doubao など、OpenAI 互換 API を持つサービスは、アドレスと API キーを入力すれば使えます。[モデルプロバイダーを追加する](providers.md) を参照してください。

**変更する前に確認します。** 4 つの権限モードがあり、「毎回確認する」から「定型作業はレビュー用のモデルに承認させる」まで選べます。どのモードでも、書き込むのは許可したフォルダーだけです。[最初の会話](first-conversation.md#permission-modes) を参照してください。

**下書きではなく完成したファイルを渡します。** ファイルを書いた後、coscribe はそれをレンダリングして結果を確認し、レイアウトと内容をチェックします。テキストの塊を渡して終わりにはしません。

## システム要件 {#system-requirements}

- Windows 10 または Windows 11。
- モデルサービスの API キー、または PC 上で動く Ollama か LM Studio。

> [!NOTE]
> coscribe は Windows 専用です。Mac 版や Linux 版はまだありません。
