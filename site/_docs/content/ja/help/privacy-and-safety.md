---
title: プライバシーと安全
description: Coscribe を使うときにコンピューターの外に出るもの、データの保存場所、操作を制御するしくみ。
---

Coscribe はあなたの PC で動きます。独自のアカウントもサーバーもなく、あなたやあなたの使い方についての情報を開発者に送ることはありません。

## コンピューターの外に出るもの {#what-leaves-your-computer}

| 送信先 | 内容 | タイミング |
|---|---|---|
| 選んだモデルプロバイダー | あなたのメッセージ、答えるために Coscribe が読んだファイルの部分、ツールの結果 | 返答のたび。[PC 上のモデル](../get-started/providers.md#run-a-model-on-your-pc) を使えば、これもコンピューター内にとどまります。 |
| 検索エンジン | 検索語 | Coscribe が Web を検索するとき。DuckDuckGo などの無料の検索エンジンを、キーなしで使います。 |
| Web サイト | 通常のページリクエスト | あなたが依頼したページや、タスクに必要なページを Coscribe が開くとき。[内蔵ブラウザー](../use/browser.md) を参照してください。 |
| つないだサービス | コネクターのツールが送る内容 | Coscribe がその [コネクター](../customize/connectors.md) を使うとき。 |

プロバイダーが何をどれだけの期間保存するかは、プロバイダー自身の規約で決まります。仕事の文書を送る前に確認してください。

## データの保存場所 {#where-your-data-is-kept}

それ以外はすべて PC に残ります。

- ファイルは元の場所にあり、Coscribe はその場で作業します。
- 会話、スケジュールタスク、スキル、設定は `%APPDATA%\Coscribe` の下にあります。
- API キーと [シークレット](../reference/settings.md#secrets) は、プレーンなファイルではなく Windows の資格情報マネージャーに保存されます。
- 各ターンの経過の記録（モデル、ツール呼び出し、エラー、トークン数、時間。会話の言葉は含みません）は、トラブルシューティングのために PC に残ります。アップロードされることはありません。

## 操作を制御するしくみ {#what-keeps-actions-in-check}

- **フォルダー**: Coscribe が書き込めるのは、ワークスペースと、あなたが許可した他のフォルダーだけです。[ワークスペースとフォルダー](../workspaces/workspaces.md) を参照してください。
- **承認**: 何かを変更する操作は、[権限モード](../use/approvals.md) に従ってあなたを待ちます。Coscribe が自身のファイルツールで削除したファイルはごみ箱に移動します。
- **スクリプト** は、Windows が許す場合は分離されたコンテナーで、ワークスペースのフォルダーに限って実行されます。分離を設定できない場合、あなたが別の選択をしない限り、スクリプトはオフです。[スクリプトと分離](../workspaces/workspaces.md#scripts-and-isolation) を参照してください。
- **サイト**: Coscribe がブラウザーで開けるサイトは、ワークスペースのサイト設定に従います。[サイトを許可する](../use/browser.md#allow-a-site) を参照してください。

> [!IMPORTANT]
> 承認はあなたによる確認であり、サンドボックスではありません。承認したスクリプトやコマンドは、分離によって制限されない限り、あなたの Windows アカウントができることを行えます。**Allow** をクリックする前に、承認カードの内容を読んでください。

## 注意すること {#things-to-watch-for}

- Web、メール、文書の文章には、AI に向けた指示が含まれていることがあります。Coscribe は読んだ内容を資料として扱い、あなたからの命令とはみなしませんが、完璧なモデルはありません。他の人が書いたものを読むタスクでは、**Never ask** と **Auto** に注意してください。
- スキル、プラグイン、コネクターは、信頼できる人のものだけを追加してください。
