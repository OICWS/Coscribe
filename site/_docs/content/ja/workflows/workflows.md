ワークフローは固定の手順でできたタスクです。書かれた指示に従うスケジュールタスクと違い、ワークフローは毎回同じ手順を実行し、実行しながらチェックします。そのため、実行する前に何をするかがわかります。スケジュール、権限、実行レポートは [スケジュールタスク](scheduled-tasks.md) と同じです。

## ワークフローを作る {#make-a-workflow}

いちばん簡単なのは、チャットで一度仕事をしてから、それをワークフローにすることです。

- coscribe が **Save this job?** と提案したとき、または **Task details** パネルで **Save as workflow** を選びます。
- または、メッセージ欄に `/saveworkflow` と入力します。続けて名前を付けてもかまいません。

coscribe が会話から手順の下書きを作ります。確認して保存します。

ゼロから始めることもできます。**Scheduled** › **New task** › **Build a workflow** です。名前とスケジュールを決めて保存し、そのページで手順を追加します。

## ワークフローのページ {#the-workflow-page}

ページには 4 つのタブがあります。

- **Overview** はワークフローがすることを平易な言葉で説明します。いつ動くか、何を扱うか、どこで止まってあなたを待つか、何に触れるか。**Show the flowchart** で手順を図にします。
- **Steps** は手順の一覧で、追加、変更、並べ替えをここで行います。**Flowchart** 表示にもできます。
- **Runs** は過去の実行の一覧です。
- **Settings** にはスケジュール、ワークスペース、権限があります。

手順がないうちは **Run now** はグレーです。ファイルなどの入力を受け取るワークフローは、まずそれを尋ねます。

## 手順の種類 {#kinds-of-steps}

**Add a step** で選べる種類：

| 手順 | 内容 |
|---|---|
| **Tool** | coscribe のツールを 1 つ使います。モデルは使いません。 |
| **Script** | 確認済みの固定の Python スクリプトを実行します。 |
| **Model** | 決まった項目を返す必要がある、1 回のモデル呼び出し。 |
| **Agent** | 設定した範囲内（呼べるツール、変更できるフォルダー、開けるサイト）でツールを使って目標に取り組みます。 |
| **Check** | 値が条件を満たさなければ実行を止めます。 |
| **Approval** | あなたが承認するまで一時停止します。 |
| **Ask you** | 後の手順で使う値をあなたが入力するまで一時停止します。 |
| **Wait** | 一定時間、指定時刻まで、またはファイルが現れるまで一時停止します。 |
| **Remember** | 処理済みのものなど、次の実行のために値を保存します。 |
| **Run a task** | 別のタスクを 1 つの手順として実行し、その結果を使います。 |
| **If / otherwise** | 値によって別の手順を実行します。 |
| **Choose a path** | 複数の経路から、値に応じて選びます。 |
| **At the same time** | 2〜6 本の手順の流れを同時に実行し、その後に進みます。 |
| **For each** | リストの各項目について手順を繰り返します。 |

各手順について、失敗したときの動きを **Stop the run**、**Skip it and go on**、**Run other steps instead** から選べます。再試行の回数も設定できます。

## 手順がうまくいかなくなったとき {#autonomy}

Web サイトは変わり、ファイルも実行ごとに違います。**If a step stops working** の設定で、そのとき AI がどこまで判断するかを決めます。

| レベル | 動き |
|---|---|
| **Fixed** | 保存した手順だけを実行します。失敗したら実行を止めて知らせます。 |
| **Self-healing** | Web サイトが変わっていたら、AI が今のページに合わせてその手順を行います。 |
| **Proactive** | AI の手順は担当部分のやり方を自分で決めます。手順が失敗したら AI が手順をいくつか追加でき、何かを変更する手順はあなたを待ちます。 |
| **Autonomous** | AI がタスク全体を自分のやり方で行えます。 |

実行が変化を回避した場合、coscribe は更新した手順を提案し、あなたが確認できます。そうすれば次の実行で同じ回避をしなくて済みます。

## イベントでワークフローを開始する {#start-on-an-event}

どのタスクにもあるスケジュールに加えて、ワークフローの **Frequency** には次も選べます。

- **Every few minutes**：数分ごと。
- **When a file arrives in a folder**：**Folder to watch** と、必要なら **File name pattern** を選びます。新しいファイルが来るたびに実行が始まり、そのファイルがワークフローのファイル入力になります。ファイルを受け取るワークフローでのみ選べます。
- **When something new shows up in a connector**：コネクターと、何を尋ねるかを選びます。coscribe が数分ごとに尋ね、新しい項目ごとに実行が始まります。最初のチェックでは、すでにあるものを確認済みとして扱います。
- **When a program sends it an event**：同じ PC 上の別のプログラムが、coscribe の表示するアドレスにキー付きでリクエストを送ります。**Wait for a sample** で次のイベントを保持し、どの項目を入力に使うかを選べます。このアドレスは自分の PC からのリクエストだけを受け付けます。

coscribe が閉じている間に届いたファイルは、coscribe を再び起動したときに実行を始めます。
